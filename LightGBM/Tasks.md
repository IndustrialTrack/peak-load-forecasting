# LightGBM

## Базовый прогноз на весь 2026 год

LightGBM однократно обучается на почасовом потреблении Челябинской области с 2022 по 2025 год. Затем модель строит 8 760 почасовых прогнозов подряд с 1 января по 31 декабря 2026 года. При расчёте следующих часов лаги пополняются уже полученными прогнозными значениями. Фактическое потребление 2026 года используется при оценке качества.

Top-3 рассчитан на 269 полных сутках с 1 января по 26 сентября. Почасовые ошибки также учитывают три фактических часа 27 сентября.

| Показатель | Значение |
|---|---:|
| Полных суток для оценки Top-3 | 269 |
| Совпавшие пиковые часы | 293 из 807 |
| **Top-3, %** | **36,31** |
| Суток с совпадением всей тройки | 8 |
| Суток без попаданий | 67 |
| Часов с фактом для почасовых метрик | 6 459 |
| MAE, МВт·ч | 156,93 |
| RMSE, МВт·ч | 196,15 |
| WAPE, % | 3,8613 |
| MAPE, % | 3,8065 |
| MAE на фактических пиках, МВт·ч | 210,25 |

Расчёт запускается командой `python forecast.py --year-ahead` из папки первой задачи. [Годовой прогноз](forecast_2026_year_ahead.csv)

Сравнение всех трёх режимов на общем периоде приведено в отдельном файле. [Сравнение режимов LightGBM](forecast_comparison_2026.md)
