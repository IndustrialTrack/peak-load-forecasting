# Прогноз потребления электроэнергии

Челябинская область. Начальное обучение: **2022–2024**, тест: **2025**, прогноз: **2026 год**. Модель ежедневно переобучается на всех доступных предыдущих наблюдениях и прогнозирует 24 часа.

За 2026 год факты в исходных данных есть до **26 сентября включительно**. С 27 сентября по 31 декабря прогноз построен рекурсивно по предыдущим прогнозам одной модели; это более длинный и менее надёжный горизонт, для него ошибок по факту нет.

## Результаты

| Период | MAE, МВт·ч | RMSE, МВт·ч | WAPE, % | MAPE, % | Часов с фактом |
|---|---:|---:|---:|---:|---:|
| Тест 2025 | 70.62 | 89.40 | 1.67 | 1.68 | 8759 |

## Пиковые часы

Пик — три часа с максимальным фактическим потреблением в течение суток. Неполные дни исключаются. Доля попаданий — число совпавших часов, делённое на три на каждый полный день.

| Период | Полных суток | MAE на пиках, МВт·ч | Найдено часов Top-3 |
|---|---:|---:|---:|
| 2025 | 364 | 90.91 | 37.27% |
| 2026 | 269 | 100.43 | 38.41% |

В тесте 2025 года отсутствует факт за 15 мая в 22:00: он не входит в ошибки, а день исключён из оценки пиков. Данные для обучения заполняются предыдущим известным значением. Сырые факты не заменяются при оценке. Пиковые часы после 26 сентября 2026 года являются только прогнозными; их фактическую точность оценить нельзя.

## Функция и параметры модели

Используются MLForecast и LightGBM. Вызов: `build_forecaster("extended_400")`.

```python
def build_forecaster(name):
    c = CONFIGS[name]
    transforms = {1: [RollingMean(24), RollingMean(168), RollingStd(24)],
                  24: [RollingMean(24)], 168: [RollingMean(24)]} if c["rolling"] else None
    return MLForecast(models={"forecast": LGBMRegressor(**c["params"])}, freq="h",
                      lags=c["lags"], date_features=c["date_features"],
                      lag_transforms=transforms, num_threads=1)
```

Параметры LightGBM: `n_estimators=400`, `learning_rate=0.03`, `num_leaves=31`, `max_depth=-1`, `min_child_samples=40`, `reg_lambda=1`, `reg_alpha=0`, `objective="regression"`, `random_state=42`, `n_jobs=2`, `deterministic=True`, `force_col_wise=True`. Все параметры указаны в `forecast.py`. Лаги: `[1, 2, 24, 25, 48, 72, 168, 169, 336]`; календарные признаки — час, день недели, месяц, день года и праздники. Лаги отражают суточную и недельную повторяемость; регуляризация ограничивает переобучение.

Параметры выбраны ранее на 28 днях 2024 года; 2025 год использован как тест. При суточной проверке после каждого дня его фактические данные добавляются в обучение. Календарные признаки повторяют исходный проект: список предпраздничных дат заканчивается 2025 годом и не заменяет производственный календарь.

## Файлы и запуск

- `forecast.py` — код без комментариев.
- `forecast_2025_2026.csv` — почасовой факт, прогноз и режим расчёта.
- `forecast.png` — сравнение прогноза и факта.
- `MAE.png`, `RMSE.png`, `WAPE_pct.png`, `MAPE_pct.png` — графики ошибок по дням, только где есть факт.
- `metrics.csv`, `daily_metrics.csv` — итоговые и дневные метрики.
- `peak_hours.csv` — фактические и предсказанные пиковые часы.
- `electricity_75.csv` — исходные данные; `test_2025.csv` — сохранённый результат теста 2025 года.

```bash
python -m pip install -r requirements.txt
python forecast.py
```

Python 3.12. Полный повторный расчёт занимает продолжительное время. Чтобы повторно рассчитать только 2026 год и использовать сохранённый тест 2025 года: `python forecast.py --start 2026-01-01`.
