## Функция и параметры модели

Используются MLForecast и LightGBM. Вызов: `build_forecaster("extended_400")`.

```python
def build_forecaster(name):
    c = CONFIGS[name]
    transforms = {1: [RollingMean(24), RollingMean(168), RollingStd(24)],
                  24: [RollingMean(24)], 168: [RollingMean(24)]} if c["rolling"] else None
    return MLForecast(models={"forecast": LGBMRegressor(**c["params"])}, freq="h",
                      lags=c["lags"], date_features=c["date_features"],
                      lag_transforms=transforms, num_threads=1)
```

Конфигурация `extended_400` берёт параметры LightGBM из `BASE_PARAMS` и переопределяет число итераций, скорость обучения, минимальное число наблюдений в листе и коэффициент L2-регуляризации. [Документация LightGBM](https://lightgbm.readthedocs.io/en/stable/Parameters.html)

| Параметр | Значение | Что означает |
|---|---|---|
| `boosting_type` | `"gbdt"` | Тип бустинга. GBDT последовательно добавляет деревья, которые уменьшают ошибку ансамбля. |
| `objective` | `"regression"` | Целевая функция обучения. Регрессия с квадратичной функцией потерь сильнее штрафует крупные ошибки прогноза. |
| `n_estimators` | `400` | Число итераций бустинга. На каждой итерации регрессор может добавить одно дерево. |
| `learning_rate` | `0.03` | Множитель вклада каждого нового дерева. Меньшее значение делает обновление прогноза более плавным. |
| `num_leaves` | `31` | Максимальное число листьев в одном дереве. Ограничивает сложность дерева. |
| `max_depth` | `-1` | Ограничение глубины дерева. Значение `-1` снимает ограничение по глубине. |
| `min_child_samples` | `40` | Минимальное число обучающих наблюдений в листе. LightGBM применяет этот порог приближённо. |
| `min_child_weight` | `0.001` | Минимальная сумма гессианов (вторых производных функции потерь) по наблюдениям в листе. |
| `min_split_gain` | `0.0` | Минимальное улучшение целевой функции, необходимое для разбиения узла. |
| `subsample` | `1.0` | Доля обучающих строк при случайной подвыборке. Значение `1.0` соответствует всем строкам. |
| `subsample_freq` | `0` | Частота обновления случайной подвыборки в итерациях бустинга. Значение `0` отключает подвыборку строк. |
| `colsample_bytree` | `1.0` | Доля признаков, доступных каждому дереву. Значение `1.0` соответствует всем доступным признакам. |
| `reg_alpha` | `0.0` | Коэффициент L1-регуляризации значений в листьях. При `0.0` штраф равен нулю. |
| `reg_lambda` | `1.0` | Коэффициент L2-регуляризации. Ограничивает слишком большие по модулю значения в листьях. |
| `max_bin` | `255` | Максимальное число интервалов, на которые LightGBM делит значения признака при построении гистограмм. |
| `subsample_for_bin` | `200000` | Максимальное число обучающих строк, используемых для вычисления границ интервалов признаков. |
| `random_state` | `42` | Начальное значение генератора случайных чисел для воспроизводимости обучения. |
| `n_jobs` | `2` | Число потоков CPU, используемых LightGBM для обучения. |
| `deterministic` | `True` | Стабилизирует результат при повторном обучении на CPU с теми же данными и настройками. |
| `force_col_wise` | `True` | Включает построение гистограмм по столбцам признаков при обучении на CPU. |
| `verbosity` | `-1` | Уровень сообщений LightGBM. При `-1` выводятся только критические ошибки. |

MLForecast формирует почасовые признаки и передаёт их регрессору. [Документация MLForecast](https://nixtlaverse.nixtla.io/mlforecast/forecast.html), [скользящие преобразования](https://nixtlaverse.nixtla.io/mlforecast/docs/how-to-guides/lag_transforms_guide.html).

| Параметр | Значение | Что означает |
|---|---|---|
| `models` | `{"forecast": LGBMRegressor(...)}` | Задаёт регрессор для обучения и имя `forecast` для столбца прогноза. |
| `freq` | `"h"` | Временной шаг ряда равен одному часу. |
| `lags` | `[1, 2, 24, 25, 48, 72, 168, 169, 336]` | Передаёт модели значения потребления указанное число часов назад. Лаги `24` и `168` соответствуют тому же часу предыдущих суток и предыдущей недели. |
| `date_features` | `["hour", "dayofweek", "month", "dayofyear"]` | Извлекает из времени наблюдения час, день недели, месяц и порядковый день года. |
| `rolling` | `True` | Включает расчёт скользящих признаков в конфигурации `extended_400`. |
| `lag_transforms` | Средние и стандартное отклонение по лагам | Для лага `1` рассчитываются средние за 24 и 168 часов и стандартное отклонение за 24 часа. Для лагов `24` и `168` рассчитывается среднее за 24 часа. Каждый интервал заканчивается в момент соответствующего лага. |
| `num_threads` | `1` | Число потоков CPU, используемых MLForecast при вычислении признаков. |

Дополнительные календарные признаки `EXOG` отмечают выходные, праздники и соседние с праздниками дни. Они также учитывают расстояние до ближайшего прошлого и будущего праздника, новогодний период и майские праздники.

Параметры модели выбраны ранее на 28 днях 2024 года. При прогнозировании на 2026 год данные за 2025 год входят в начальную обучающую выборку. Список предпраздничных дат охватывает 2022–2025 годы.
