# Задача 1. Скользящее прогнозирование

**Данные взяты с 01.01.2022 по 31.12.2024, код реализует почасовой прогноз потребления электроэнергии на сутки вперёд с ежедневным переобучением модели по схеме walk-forward (скользящее расширяющееся окно). Итоговый прогноз за год собирается из 365 независимых суточных прогнозов — по одному на каждый день 2025 года.**

**На картинках представлены графики метрик на каждый день за весь 2025 год.**

Для прогнозирования используется модель LightGBM; код и конфигурация доступны в репозитории. Оценка выполняется в условиях, приближенных к реальной эксплуатации: на каждый день прогноз строится только по данным, доступным к моменту его формирования, после чего фактический день добавляется в обучающую выборку, и процедура повторяется для следующего дня. Такой протокол позволяет корректно оценить качество суточного почасового прогноза на всём протяжении 2025 года.

## Метрики оценки качества прогноза

- MAE — 75,81 МВт·ч
- RMSE — 95,70 МВт·ч
- WAPE — 1,79 %
- MAPE — 1,80 %

## Вывод

Полученные значения метрик свидетельствуют о высокой точности модели LightGBM: все четыре метрики находятся на низком уровне, средняя абсолютная ошибка за час невелика, а относительная ошибка за 2025 год составляет малую долю от общего фактического потребления, при этом превышение RMSE над MAE указывает на наличие отдельных часов с более крупными отклонениями, вероятно в периоды пиковых нагрузок, поэтому именно прогнозирование пиковых часов остаётся основным направлением для дальнейшего улучшения модели.
