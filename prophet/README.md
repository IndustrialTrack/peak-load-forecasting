# Прогноз топ-3 пиковых часов энергопотребления

**Модель:** Prophet\
**Период оценки:** 1 января --- 19 сентября 2026 года (262 дня)\
**Регионы:** Тюменская и Челябинская области

## 1. Протокол эксперимента

-   Прогноз строится на сутки вперёд, точка прогноза --- 00:00.
-   Для каждого дня с 2026-01-01 по 2026-09-19 обучение проводится на
    всей истории, доступной строго до 00:00 этого дня.
-   Используется расширяющееся окно обучения с ежедневным переобучением.
-   Предобработка одинакова для всех вариантов.
-   Подбор параметров выполнялся на 37 датах периода 2025-01-01 ---
    2025-12-31 с шагом 10 дней. Данные тестового периода при подборе не
    использовались.
-   Критерии подбора: MAPE и MAPE в пиковые часы.
-   Движок прогнозирования: Prophet.

### Сравниваемые варианты

  -----------------------------------------------------------------------
  Вариант                             Описание
  ----------------------------------- -----------------------------------
  `prophet_current`                   Вариант прежнего кода. Использует
                                      цену того же часа, которая в момент
                                      прогноза недоступна. Это утечка
                                      данных; вариант оставлен для
                                      сравнения.

  `prophet`                           Честный вариант: использует цену за
                                      сутки до прогнозируемого момента.

  `prophet_nbr`                       Prophet с дополнительным
                                      регрессором --- потреблением
                                      соседних регионов за сутки до
                                      прогнозируемого момента.
  -----------------------------------------------------------------------

Метрики рассчитываются только на днях, для которых прогнозы имеются у
всех сравниваемых вариантов.

### Выбранные параметры

  Вариант               `cps`
  ------------------- -------
  `prophet`              0.05
  `prophet_current`      0.01
  `prophet_nbr`           0.1

**Hit rate топ-3** --- доля часов среди трёх предсказанных пиковых
часов, которые совпали с тремя фактическими пиковыми часами суток.
