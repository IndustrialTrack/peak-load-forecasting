# Прогнозирование пиковых часов электропотребления энергосистемы на сутки вперед

Программный модуль для автоматизированного сбора исторических данных об электропотреблении и прогнозирования **трёх наиболее нагруженных часов следующего дня** для выбранной энергосистемы (региона).

Проект предназначен для исследования применимости статистических методов и методов машинного обучения к задаче прогнозирования суточного профиля электропотребления и выявления часов локального максимума нагрузки.

---

## О проекте

Точное определение часов максимального электропотребления важно для планирования режимов работы энергосистемы и анализа нагрузки.

Исторические почасовые данные о фактическом потреблении доступны на портале [Системного оператора Единой энергетической системы](https://br.so-ups.ru/). Однако для проведения регулярного анализа необходимо самостоятельно собирать исторические данные, обрабатывать их и формировать прогноз на следующие сутки.

## Цель

Разработать программный модуль сбора данных с портала СО ЕЭС и построения вероятностного прогноза **трёх наиболее нагруженных часов электропотребления на следующие сутки** для выбранной энергосистемы или региона.

---

## Основные задачи

1. Разработать модуль автоматизированного сбора почасовых данных с портала СО ЕЭС.
2. Сформировать исторический датасет за период не менее 2–3 лет.
3. Выполнить предварительную обработку данных:

   * обработку пропусков;
   * обнаружение выбросов;
   * проверку временной последовательности;
   * обработку переходов на летнее/зимнее время при наличии;
   * контроль корректности значений.
4. Исследовать закономерности суточного и недельного профиля электропотребления.
5. Реализовать статистические базовые модели.
6. Реализовать модели машинного обучения и/или глубокого обучения.
7. Сформировать прогноз почасового потребления на следующие сутки.
8. Определить три часа с максимальным прогнозируемым потреблением.
9. Рассчитать вероятностную оценку попадания каждого часа в Top-3.
10. Провести сравнительный анализ моделей на отложенной тестовой выборке.

## Данные

Источником исторических данных является портал Системного оператора Единой энергетической системы:

**Источник:** [br.so-ups.ru](https://br.so-ups.ru/)

Для каждого часа сохраняются данные о фактическом электропотреблении выбранной энергосистемы/региона.

Предполагаемый период исторических данных:

```text
2022–2025
```

или другой период, достаточный для формирования репрезентативной обучающей выборки.

Пример структуры данных:

| Поле                 | Описание                           |
| -------------------- | ---------------------------------- |
| `datetime`           | Дата и час измерения               |
| `region`             | Энергосистема / регион             |
| `actual_consumption` | Фактическое потребление, МВт·ч     |
| `hour`               | Час суток                          |
| `day_of_week`        | День недели                        |
| `is_holiday`         | Признак выходного/праздничного дня |

Набор признаков может расширяться в процессе исследования.

## Прогнозируемая величина

Основной объект прогнозирования — почасовое электропотребление на следующие сутки:

```text
D + 1
```

Для каждого из 24 часов следующего дня модель формирует прогноз:

```text
ŷ₁, ŷ₂, ..., ŷ₂₄
```

После этого часы сортируются по прогнозируемому уровню нагрузки.

Например:

```text
15:00 → 4180 МВт
16:00 → 4250 МВт
17:00 → 4310 МВт
...
```

Три часа с наибольшим прогнозируемым значением формируют прогнозируемый Top-3.

---

## Вероятностный прогноз

Помимо ранжирования часов, система должна оценивать степень уверенности модели.

Пример результата:

```text
Дата: 25.09.2026

Прогнозируемые пиковые часы:

1. 18:00 — 4310 МВт — Probability: 0.72
2. 17:00 — 4285 МВт — Probability: 0.64
3. 19:00 — 4250 МВт — Probability: 0.51
```

Probability Score интерпретируется как оценка вероятности того, что соответствующий час попадёт в фактическую тройку наиболее нагруженных часов.

Для получения вероятностных оценок может использоваться отдельный этап калибровки модели.
